## 远征规则

| 阶段 | 当前规则 |
| --- | --- |
| 营地 | 八方向自由行走；免费选择六种武器、两顶帽子、两条围巾和四种坐骑；默认步行 |
| 普通波 | 有限敌人全部出场且清场后，选一张普通增强卡；3 秒休整后下一波 |
| 第 5 / 10 / 15 / 20 / 25 / 30 波 | 各出现一只精英蟹；奖励依次为精良 / 稀有 / 史诗 / 传说 / 神话 / 超凡 |
| 精英卡 | 基础增益倍率依次为 2 / 3 / 4 / 5 / 6 / 7，接近能力上限时按剩余额度计算，页面显示实际数值 |
| 第 10 / 20 / 30 波清场 | 先选精英卡，再进入熊猫强化页；精粹升级武器、帽子、围巾和车架，单项最高 +5 |
| 第 30 波 | 本波同时有精英与寄居蟹首领；全部击败，完成选卡和强化后通关 |
| 地图通关 | 保留武器、穿戴、坐骑、强化等级、卡片、精粹和当前体力；可回营地保留远征 |
| 下一地图 | 待完善，入口禁用；没有占位地图或未实现的新敌人 |
| 失败 / 主动结束 / 重开 | 清零本次卡片、精粹、装备强化；保留基础配置和纪录 |

取消 180 秒生存目标和 135 秒首领计时。首张地图为 2400 × 1700 海岸，双轴相机跟随；每波普通敌人数 `5 + floor(波次 × 1.1)`，精英和首领额外加入。怪物体力、攻击、速度随波次增长，15 波起精英增加扇形远射，首领半血后加强弹幕与冲锋。数值是初始实现参数，未验证平衡或可通关性。

精粹沿用既有晶体美术。每次击杀掉落基础价值加 `floor(波次 / 10)`，清场自动回收剩余掉落。强化费用为：武器 `22 × (当前等级+1)`，帽子/围巾 `18 × (当前等级+1)`，车架 `20 × (当前等级+1)`；另可花 18 精粹恢复 40% 最大体力。精粹可留待后续休整。

武器每级增加 12% 独立伤害倍率；帽子和围巾按登记效果逐级提升；车架每级增加 4% 骑乘速度倍率、15% 坐骑攻击倍率。全新远征从 +0 出发，原版永久天赋、装备等级、海贝均不进入本项目。

## 操作与营地

| 操作 | 键盘 / 触屏 |
| --- | --- |
| 八方向移动 | WASD / 方向键 / 摇杆 |
| 普通攻击 | 冒险中自动瞄准近敌；J / 攻击按钮可主动出手 |
| 武器特色 | K / 特色：弓、太刀、巨锤蓄力松开，刀盾举盾，法杖范围法术，散弹枪装填 |
| 跳跃 / 跳击 | 空格 / 跳跃按钮 |
| 闪避 / 冲撞 | Shift / 动作，沿最近移动方向 |
| 上下车 | R / 坐骑，冷却不重置 |
| 交互 | E / 交互按钮；底部路标可自动走向建筑 |
| 暂停 | P / Esc；所有窗口冻结战斗与冷却 |
| 选卡 | 1 / 2 / 3 或点击 |

自动普攻可被主动特色、跳跃、冲撞和上下车打断。骑乘仍能使用六类武器。普通车加速、山地车跳击、公路车快速冲撞、摩托车兼具跳击/冲撞/定时远射；跳跃和冲撞不是全程无敌。

铁匠铺选基础穿戴，旁边武器架换武器，木桩试招无收益，停车点选四种车辆。学堂说明卡片，行政厅展示目标和纪录，公告栏显示更新，冒险入口管理新出发与通关配置。没有永久天赋、永久强化或海贝领奖。
