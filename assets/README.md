## 波次远征的接入

当前项目是独立副本，`sprites.svg` 与原 v0.3.2 完全一致，全部 ID、runtimeKey、造型修订号和挂点保持。资产库 1.1.1 只增加 `projectUsage` 新项目用途；原 actions/definition 保留基线资料，图鉴分别显示。场景位置由 `townLayout` 实例布局决定，怪物按波次增幅，装备强化只在局内生效。原珍珠晶体现在代表精粹，不再是经验。下文原版说明中提及海贝、横版和原场景位置时作为历史基线理解。

游戏启动仍只需打开 `index.html`，无需联网、服务器或构建。开发时改完资产源运行：

```sh
python3 tools/sync_assets.py
```

只核对目录、图形引用与生成区是否同步：

```sh
python3 tools/sync_assets.py --check
```

此检查不执行游戏或试玩。同步工具仅修改入口的两个标记区与图鉴，不改玩法脚本、旧快照或版本日志。每批完成修改仍按项目规则登记游戏版本、修改编号和新快照。

两张 PNG 是可选导出，需已有的 `sharp` 和与其架构匹配的 Node.js；这不是游戏依赖。本轮使用 Codex 自带的运行时，没有安装包。图形变化后先同步图鉴，再导出两张预览；一般命令为 `node tools/render_asset_sheet.cjs`，已有包在其他位置时通过 `NODE_PATH` 指定。当前电脑可复用以下命令：

```sh
NODE_PATH='/Users/qianweijin/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/node_modules' '/Users/qianweijin/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin/node' tools/render_asset_sheet.cjs
```

总览上所有卡片按各自展示框缩放，不能把卡片之间的像素大小当作游戏中的实际体型比例；精英蟹在游戏中仍为普通蟹的 1.5 倍。

## 接入与变更

1. **使用现有资产**：先在图鉴或目录查编号，复用 `visual.id` 和已有配置。游戏通过 `contentTable()` 读取武器、车辆、穿戴、建筑、怪物；通过 `sprite()` 引用静态图形，通过 `assetMarkup()` 填充可动画装备槽。
2. **新增摆放或实例**：引用原资产，位置、朝向、动作状态属于实例。不要复制一套 SVG 路径再微调，不为每张地图重画同一建筑或角色。
3. **新增动画或姿态**：沿用 CHR-001 的骨架与比例，操作 `data-part` 挂点；身体、帽子、围巾、武器、车辆独立。缺少的姿态先明确动画需求，不整只重做角色。
4. **调整原资产**：只改对应源条目，条目 `revision` 加 1，在开发日志说明外观、挂点或数值的变化。普通数值调整不自动更换外形。重设计轮廓按用户明确需求开展。
5. **新增不同物品/皮肤**：新建 ID，写明 `dependencies` 或变体来源。不得用新造型静默覆盖旧编号。新 `runtimeKey` 如需新的动作逻辑，在相关函数中接入；登记卡片不会自动创造新玩法。
6. **同步并交付**：运行同步命令，进行约定范围的检查，更新版本与快照。生成区和图鉴不是第二份可独立改动的源。

## 图形与坐标约定

- 游戏 SVG 单位作为设计单位；卡片 `viewBox` 只用于展示，不决定攻击/受击判定。
- 鹈鹕地面脚点 `(0,0)`，默认朝右，Y 向下；`lift` 承担跳跃、`facing` 承担镜像、`shadow` 留在地面。身体偏移 `(0,-31)`，手持点 `(21,-40)`，武器缩放 `0.72`。
- 车辆后/前轮心分别为 `(-29,-13)` / `(29,-13)`；轮辐使用 `data-part="wheel"` 与局部轮心旋转，不依靠 DOM 顺序猜轮子。
- 帽子和围巾图形使用人物本地坐标直接挂载；围巾的 `data-part="tail"` 是包含飘带、阴影与纹样的组，绕 `(10,-55)` 摆动。不得写回旧版统一 `d` 路径或再套一层重复平移。
- 刀盾、太刀、巨锤、法杖在图形源内分别绕握点预转 20°、15°、30°、35°，使站姿武器避开嘴部；实际动作仍使用原手持点。陈列、卡片与游戏共用该方向，不为预览另调一套。
- 居民对话头像与建筑内居民共用 symbol；武器架陈列共用武器；停车点陈列共用四车。
- 配色沿用奶油、鼠尾草绿、珊瑚橙、木色与黄铜；闭合轮廓使用圆角描边，一层阴影和少量高光区分材质。以小尺寸可读性为先，后续日常复用不自动重画。

红帆围巾为短开叉尾与缝线，海风围巾为长尖尾与海浪纹；精英蟹已有独立甲壳。NPC 仍为静态立绘，停车点仍为开放设施；铁匠铺炉火/烟与怪物细节是静态图形，并未增加全套动作帧。PNG 总览和六种装备组合已查看，未运行游戏或浏览器试玩，卡片不把静态预览写成动作验收。
